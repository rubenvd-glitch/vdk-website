Privacy — Base

Wat Base van je opslaat en hoe daarmee wordt omgegaan.
Je gesprekken met Base worden opgeslagen in jouw eigen beveiligde database (Upstash), gekoppeld aan jouw account. Niemand anders kan ze zien.
Om te kunnen antwoorden stuurt Base je vraag en relevante gegevens (zoals openstaande herinneringen of Gym-doelen) naar Groq, de AI-provider die de antwoorden genereert. Groq gebruikt deze gegevens nooit om zijn modellen te trainen — dat was een bewuste keuze bij het kiezen van deze provider.
Base houdt bij op welk type proactieve melding (een herinnering, een Gym-doel, een idee, enz.) je reageert of juist niet, puur om te leren wat voor jou belangrijk is. Deze gegevens verlaten nooit je eigen account en worden nergens anders voor gebruikt dan om te bepalen wat Base je in het vervolg wel of niet voorlegt — nooit om zelf iets te doen of te delen.
Base voert nooit zelf iets uit. Bij elke voorgestelde actie (een herinnering aanmaken, een set loggen, enz.) vraagt hij altijd eerst om bevestiging via een knop.
Je kunt je gesprek met Base op elk moment wissen via de prullenbak-knop in de chatbalk.
